# 前言 (Introduction)

欢迎来到《高性能Rust：方法、实现与优化》。

本书聚焦于一个更完整的问题：如何把 Rust 的内存安全、类型系统与并发模型，落实到高性能程序与系统的设计、实现与验证中。这里的高性能并不只指低延迟，还包括吞吐量、资源效率、可预测性以及在多核环境下的扩展能力。讨论不会停留在语言特性本身，而是把 Rust 放回真实的系统上下文中考察：缓存层次、内存布局、原子操作、网络 I/O、消息处理、控制链路与性能分析。电子市场、订单流与风控等内容主要作为贯穿全书的应用案例，用来承载对高性能系统问题的具体讨论，而不是把全书限定为一部面向单一行业的专门手册。

## 本书路线图

本书分为六个部分，由浅入深地建立一条从语言机制到底层系统、再到领域应用与性能验证的技术路径：

1.  **系统基础与性能模型 (Foundations)**：建立 CPU、操作系统、内存层次、编译器与并发模型的分析框架。
2.  **Rust 语义与抽象成本 (Rust Cost Model)**：系统整理所有权、生命周期、泛型、内部可变性与错误处理等构建高性能程序时必须掌握的语言能力。
3.  **吞吐量、并发与基础设施 (Concurrency & Throughput)**：讨论原子操作、无锁队列、Ring Buffer、日志、配置与监控等基础组件，并补充批处理、背压、资源效率与可扩展性设计。
4.  **网络与高性能 I/O (Network & I/O)**：从常规 I/O 模型出发，逐步过渡到 io_uring 与内核旁路方案。
5.  **应用专题：电子市场消息系统 (Applications)**：以电子市场消息系统为案例，讨论协议解析、行情快照、订单簿、路由、风控与执行链路。
6.  **性能工程与验证 (Performance Engineering)**：用基准测试、性能分析、CPU 隔离、FPGA 协同、事件驱动回放与时钟模拟验证系统设计。
