# 前言 (Introduction)

欢迎来到《Effective Rust：面向低延迟系统的设计与实战》。

本书聚焦于一个明确的问题：如何把 Rust 的内存安全、类型系统与并发模型，落实到低延迟系统的设计、实现与验证中。讨论不会停留在语言特性本身，而是把 Rust 放回真实的系统上下文中考察：缓存层次、内存布局、原子操作、网络 I/O、消息处理、控制链路与性能分析。电子市场、订单流与风控等内容主要作为贯穿全书的应用案例，用来承载对低延迟系统问题的具体讨论，而不是把全书限定为一部面向量化交易系统实现的专门手册。

## 本书路线图

本书分为七个部分，由浅入深地建立一条从语言机制到底层系统、再到领域应用与性能验证的技术路径：

1.  **系统基础与性能模型 (Foundations)**：建立 CPU、操作系统、内存层次、编译器与并发模型的分析框架。
2.  **Rust 核心语义与抽象机制 (Advanced Rust Features)**：系统整理生命周期、泛型、宏、内部可变性、Send/Sync 等构建高性能程序时必须掌握的语言能力。
3.  **并发原语与基础设施 (Core Infrastructure)**：讨论原子操作、无锁队列、Ring Buffer、日志、配置与监控等基础组件。
4.  **网络与高性能 I/O (Network & I/O)**：从常规 I/O 模型出发，逐步过渡到 io_uring 与内核旁路方案。
5.  **应用专题：电子市场与消息处理 (Electronic Markets)**：以电子市场消息系统为案例，讨论协议解析、行情快照、增量更新与订单路由。
6.  **应用专题：低延迟引擎与控制链路 (Execution Architecture)**：围绕订单簿、风控、持仓、信号与执行，分析低延迟控制链路的组织方式。
7.  **性能验证、部署优化与仿真 (Optimization & Simulation)**：用基准测试、性能分析、CPU 隔离、FPGA 协同、事件驱动回放与时钟模拟验证系统设计。
