# 吞吐量、并发与基础设施 (Concurrency & Throughput)

本部分从可共享状态的最小单位开始，逐步过渡到完整的基础设施组件。原子操作、内存顺序、无锁结构、Ring Buffer、队列、日志、配置与监控，构成了高性能系统中最常见的一组工程骨架。

这里的重点不是“从零重复造轮子”，而是理解这些轮子为什么这样设计：哪些约束来自硬件缓存一致性，哪些约束来自线程间通信，哪些约束服务于吞吐量，哪些约束又服务于稳定性与可观测性。

## 新人学习顺序

| 优先级 | 章节 | 面试目标 |
| --- | --- | --- |
| P0 必会 | 吞吐量与背压、队列、原子操作基础、日志与指标 | 会解释瓶颈、队列满和可观测性，不把“无锁”当万能答案 |
| P1 应会 | Ring Buffer 原理、无锁进展保证、资源效率、扩展性、配置热更新 | 能画出所有权和数据流，说明一致性与降级策略 |
| P2 选读 | 手写 `unsafe` 容器、ABA/回收算法、特定库内部实现 | 只有岗位要求底层并发实现或简历声称做过时深入 |

建议先读吞吐和背压，再返回原子与队列。否则很容易学会 CAS 指令，却回答不了“队列为什么存在、满了怎么办”。
