# 概率、组合计数与统计直觉

程序处理随机到达的请求、哈希碰撞、采样、重试和测量噪声时，不能只回答“有可能发生”。我们需要一个可计算的模型：可能结果有哪些，每类结果有多大概率，重复试验的平均结果和波动分别是什么。

本章只讲开发岗位会直接使用的基础概率与统计。随机过程、期权定价、随机微积分和交易策略不在这里；它们属于其他岗位或专门课程，并不是理解哈希、随机算法和系统测量的前提。

## 1. 随机试验、样本空间与事件

**随机试验**是在条件确定后，单次结果仍不能预先唯一确定的过程。例如一次请求是否超时、一次均匀哈希落到哪个桶。

**样本空间** `Ω` 是所有可能基本结果的集合。抛一枚普通硬币一次，可以写成：

```text
Ω = {正面, 反面}
```

**事件**是样本空间的一个子集。例如掷一枚六面骰子：

```text
Ω = {1, 2, 3, 4, 5, 6}
A = {2, 4, 6}       // 点数为偶数
B = {4, 5, 6}       // 点数至少为 4
```

集合运算直接对应事件关系：

- `A ∪ B`：A 或 B 至少一个发生；
- `A ∩ B`：A 与 B 同时发生；
- `Aᶜ`：A 不发生；
- `A \ B`：A 发生但 B 不发生。

先写清样本空间很重要。“随机选一个请求”究竟是从所有到达请求、所有成功请求，还是每个用户先等权抽一个，请求被抽中的概率都可能不同。

## 2. 先计数，再计算等可能结果的概率

只有当有限样本空间中的基本结果**等可能**时，才可以直接使用：

```text
P(A) = A 中结果数 / Ω 中结果总数
```

如果服务器收到的请求类型本来就不均匀，不能因为有三种类型就说每种概率是 `1/3`。

### 2.1 加法原理与乘法原理

- 一个任务可以用 `m` 种互斥方式完成，另一个替代任务可以用 `n` 种互斥方式完成，二选一共有 `m+n` 种；
- 一个过程先有 `m` 种选择，每种选择后都有 `n` 种下一步，完整过程共有 `m×n` 种。

例如一个测试矩阵包含 3 种操作系统和 2 种编译器，每种组合都要测试，共有 `3×2=6` 种环境。

### 2.2 排列与组合

从 `n` 个互不相同对象中选 `k` 个：

- **排列**关心顺序：

```text
P(n,k) = n! / (n-k)!
```

- **组合**不关心顺序：

```text
C(n,k) = n! / [k!(n-k)!]
```

从 8 个节点中选 3 个做检查副本，节点集合相同就算同一种方案，因此是 `C(8,3)=56`，不是排列数 `8×7×6=336`。若还要分别指定 leader、第一 follower、第二 follower，角色有顺序，才使用排列。

实际编程不应先算三个巨大阶乘再相除，因为中间值可能溢出。可以利用 `C(n,k)=C(n,n-k)`，逐步做乘除，并在每一步检查数值范围。

## 3. 三条概率基本规则

对任意事件 A、B：

```text
0 ≤ P(A) ≤ 1
P(Ω) = 1
P(Aᶜ) = 1 - P(A)
```

两个事件的并集满足容斥：

```text
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
```

减去交集，是因为 `P(A)+P(B)` 把同时属于 A、B 的结果数了两次。

例如 100 个故障样本中，40 个被 CPU 告警规则命中，25 个被内存规则命中，其中 10 个同时命中：

```text
至少被一种规则命中 = 40 + 25 - 10 = 55
P(CPU 告警或内存告警) = 55 / 100 = 0.55
```

多个事件“至少一个发生”常用补集更简单。若每次独立请求成功概率为 `p`，连续 `k` 次至少成功一次：

```text
P(至少成功一次) = 1 - P(全部失败)
                  = 1 - (1-p)^k
```

独立性是这个乘法的前提。共享同一故障域的多次请求通常不独立，不能机械套公式。

## 4. 条件概率：已经知道一件事后重新缩小范围

**条件概率** `P(A|B)` 表示已知 B 发生时，A 发生的概率：

```text
P(A|B) = P(A ∩ B) / P(B), 其中 P(B) > 0
```

分母从整个样本空间变成事件 B。由定义可得到乘法公式：

```text
P(A ∩ B) = P(B)P(A|B) = P(A)P(B|A)
```

### 4.1 全概率公式

若 `B₁...Bₙ` 两两互斥并覆盖整个样本空间，那么：

```text
P(A) = Σ P(A|Bᵢ)P(Bᵢ)
```

它的意思是：按不同来源拆开计算 A，再把每个来源的贡献加起来。

### 4.2 Bayes 公式：从结果反推来源

Bayes 公式只是把同一个交集用另一种顺序展开：

```text
P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ) / P(A)
```

假设真实故障率为 1%；监控对故障的检出率是 90%，对正常请求的误报率是 5%。收到告警后，真实故障概率不是 90%。先画 10,000 个请求的频数表：

| 实际状态 | 数量 | 告警比例 | 告警数量 |
|---|---:|---:|---:|
| 故障 | 100 | 90% | 90 |
| 正常 | 9,900 | 5% | 495 |

所以：

```text
P(故障 | 告警) = 90 / (90 + 495)
                 ≈ 0.1538
                 = 15.38%
```

检出率很高却仍有很多误报，是因为正常请求的基数远大于故障请求。这叫基础率影响；计算时不能丢掉先验概率 `P(故障)`。

## 5. 独立与互斥不是同一件事

A 与 B **独立**表示知道其中一个发生，不改变另一个的概率：

```text
P(A ∩ B) = P(A)P(B)
```

A 与 B **互斥**表示它们不能同时发生：

```text
A ∩ B = ∅
```

两个概率都大于 0 的互斥事件一定不独立。因为互斥给出 `P(A∩B)=0`，而独立会要求 `P(A∩B)=P(A)P(B)>0`。

例子：一次骰子结果为“奇数”和“偶数”互斥；两次相互独立掷骰时，“第一次为偶数”与“第二次为偶数”独立。

工程里最危险的错误是假设重复请求独立。两个请求若共享机器、交换机、数据库或同一段高峰时间，它们会受到共同原因影响。重试成功率、冗余可用性和抽样误差都必须说明独立假设是否合理。

## 6. 随机变量把结果映射成数字

**随机变量**是从样本结果到数字的函数。它不是“变量自己随机移动”，而是用数字表示我们关心的结果，例如一次请求的重试次数、一个桶中的键数量。

离散随机变量 X 的**概率质量函数**写成：

```text
p(x) = P(X=x)
```

所有可能值的概率之和为 1。

### 6.1 Bernoulli 分布

一次试验只有成功与失败：

```text
X = 1，概率 p
X = 0，概率 1-p
```

则：

```text
E[X] = p
Var(X) = p(1-p)
```

### 6.2 Binomial 分布

做 `n` 次相互独立、成功概率都为 `p` 的 Bernoulli 试验，成功总次数 `X` 服从二项分布：

```text
P(X=k) = C(n,k)p^k(1-p)^(n-k)
E[X] = np
Var(X) = np(1-p)
```

“独立且每次 p 相同”不能省略。流量随时间变化或故障成批发生时，二项模型可能不适用。

### 6.3 Geometric 分布

重复独立试验，直到第一次成功。若 X 表示**包含成功那次在内的试验次数**：

```text
P(X=k) = (1-p)^(k-1)p
E[X] = 1/p
```

有的资料把 X 定义为成功前的失败次数，此时均值为 `(1-p)/p`。看到公式前必须先确认随机变量定义。

### 6.4 Poisson 分布

Poisson 分布常用于描述固定时间或空间范围内的事件计数。若平均发生次数为 `λ>0`，则：

```text
P(X=k) = e^(-λ) λ^k / k!, k=0,1,2,...
E[X] = λ
Var(X) = λ
```

例如某独立错误在 10 分钟内平均出现 2 次，用 Poisson 教学模型估算“10 分钟内一次都没有”：

```text
P(X=0) = e^(-2) ≈ 0.1353
```

使用它要说明假设：所选区间内平均速率近似稳定，事件不会明显成批，并且小区间发生多个事件的概率足够小。流量潮汐、共同故障或重试风暴会破坏这些假设。

### 6.5 均匀分布与正态分布

离散均匀分布表示有限结果等概率，例如公平骰子。连续均匀分布 `U(a,b)` 在区间内具有恒定密度，其均值为 `(a+b)/2`。连续变量恰好等于某一个点的概率为 0；概率来自区间面积，不能把“密度值”直接当点概率。

正态分布 `N(μ,σ²)` 由均值和方差确定，曲线关于 μ 对称。把 `X` 标准化为：

```text
Z = (X-μ)/σ
```

就能用标准正态分布计算区间概率。正态不是“任何数据最终都会长这样”；延迟、文件大小等数据常偏斜或重尾。它更常在测量误差、许多小影响叠加，或样本均值的近似分布中出现。

## 7. 期望：长期加权平均，不是单次保证

离散随机变量的期望为：

```text
E[X] = Σ xP(X=x)
```

期望可以不是 X 的可能取值。例如公平六面骰子的期望是 3.5，但单次不会掷出 3.5。

### 7.1 期望的线性性质

无论 X、Y 是否独立，都有：

```text
E[aX+bY+c] = aE[X] + bE[Y] + c
```

这条性质常比直接枚举联合分布简单。

### 7.2 指示变量

事件 A 的指示变量定义为：

```text
I_A = 1，A 发生
I_A = 0，A 不发生
```

于是 `E[I_A]=P(A)`。把总数量写成许多指示变量之和，就能直接使用期望线性性。

例如 100 个任务中，第 i 个任务需要重试的概率为 2%。令 `I_i` 表示它是否重试，则重试总数 `R=ΣI_i`：

```text
E[R] = ΣE[I_i] = 100 × 0.02 = 2
```

求期望时不需要这些事件彼此独立；但要计算方差或尾部概率，相关性会变得重要。

### 7.3 哈希桶的平均负载

把 1,000 个键独立、均匀地哈希到 100 个桶。对固定桶 j，令每个键是否进入 j 为指示变量：

```text
E[桶 j 的键数] = 1000 × (1/100) = 10
```

“固定桶平均 10 个键”不表示每个桶恰好 10 个，也不能直接推出最大桶大小。期望描述平均，容量规划还要考虑方差和尾部。

## 8. 方差、标准差与协方差

期望描述中心，**方差**描述围绕期望的平方偏离：

```text
Var(X) = E[(X-E[X])²]
       = E[X²] - E[X]²
```

**标准差**是 `sqrt(Var(X))`，单位与 X 相同。若延迟单位是毫秒，方差单位是平方毫秒，标准差又回到毫秒。

线性变换满足：

```text
Var(aX+b) = a²Var(X)
```

两个变量相加时：

```text
Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)
```

其中协方差为：

```text
Cov(X,Y) = E[(X-E[X])(Y-E[Y])]
```

X、Y 独立时协方差为 0，所以方差可以直接相加；协方差为 0 却不一定能反推独立。

例如两个独立处理阶段的标准差分别为 3 ms 和 4 ms，则总时长方差为 `3²+4²=25 ms²`，标准差为 `5 ms`，不是 `3+4=7 ms`。如果两阶段都因同一次主机抖动一起变慢，协方差为正，直接按独立相加会低估波动。

### 8.1 总体与样本统计量

如果手中的 n 个数就是关心的全部总体，总体方差常写成：

```text
σ² = Σ(xᵢ-x̄)² / n
```

若这些数只是从更大总体抽出的独立同分布样本，并希望无偏估计总体方差，常使用：

```text
s² = Σ(xᵢ-x̄)² / (n-1), n ≥ 2
```

分母不是一个可以随意选择的格式差异；先说明数据角色和估计目标。在线稳定计算见[流式与工程算法](streaming_systems.md)中的 Welford 算法。

平均数和标准差也不能替代分位数。系统延迟可能偏斜、重尾或多峰，此时 p50/p99、最大值、样本量和时间窗口仍要单独报告。

## 9. 从样本推断总体：LLN、CLT 与置信区间

### 9.1 大数定律回答“平均值会不会稳定”

在独立同分布、期望存在等条件下，样本量增大时，样本均值会趋近总体期望。这是**大数定律（Law of Large Numbers，LLN）**的核心直觉。

它不表示样本均值随 n 单调变好，也不表示任意相关、重尾数据都快速收敛。连续压测的一百万个相邻请求若共享同一台过热机器，不能自动当作一百万个独立样本。

### 9.2 中心极限定理回答“均值怎样波动”

在常见条件下，独立同分布样本的均值在样本量较大时近似正态，中心在 `μ`，标准差为：

```text
SE = σ/√n
```

`SE` 是样本均值的**标准误（standard error）**，不是原始样本的标准差。样本量增加 4 倍，标准误约减半；不是减少为四分之一。

CLT 讨论的是样本和/均值的标准化分布，不声称原始数据本身变成正态。重尾、强相关或样本过小时，近似可能很差，应使用重采样、稳健统计或更合适模型验证。

### 9.3 置信区间

若独立样本量足够大，用样本标准差 s 近似 σ，均值的教学近似 95% 置信区间是：

```text
x̄ ± 1.96 × s/√n
```

例如 100 次独立测量的平均值为 50 ms，样本标准差为 10 ms：

```text
SE = 10/√100 = 1 ms
区间约为 50 ± 1.96 ms = [48.04, 51.96] ms
```

频率学派的准确表述是：若按同一抽样和构造程序重复实验，长期约 95% 这样的区间会覆盖固定真值。一次已经算出的区间不是给固定参数重新赋 95% 随机概率。小样本且方差未知时常用 t 分布；时间序列相关时还要调整有效样本量。

### 9.4 假设检验与 p-value

假设检验先写原假设 `H0`，例如“新旧实现的总体均值相同”，再选择统计量和在 `H0` 成立时的分布。**p-value**是在 `H0` 成立的前提下，观察到当前或更极端结果的概率。

它不是 `H0` 为真的概率、改动有效的概率，也不是效果足够大的证明。显著性水平 α 控制第一类错误（真实 H0 被拒绝）的长期上限；第二类错误是存在真实差异却未拒绝 H0，`1-β` 称为 power（检验功效）。工程决策还要报告效果量、置信区间、样本设计与业务门槛。反复尝试许多指标只挑 `p<0.05` 的一个，会增加假阳性，需要预先定义主要指标或做多重比较控制。

## 10. 随机算法中的“期望”与“最坏”

随机化可以让固定输入较难持续制造坏路径，但不能自动消灭最坏情况。

- 随机 pivot 的快速排序期望 `O(n log n)`，单次最坏仍为 `O(n²)`；
- 随机 Quickselect 期望 `O(n)`，单次最坏仍为 `O(n²)`；
- 哈希表在分布合理时平均查找接近常数，碰撞严重时仍可能退化；
- 水库抽样能在未知流长度下保持等概率样本，但它给的是抽样保证，不保存全部数据。

回答复杂度时要说明随机性来自输入分布还是算法自己的随机选择，并明确结论是平均、期望、摊还还是最坏界。

### 10.1 哈希碰撞的两个不同问题

把 n 个不同键独立均匀哈希到 m 个值。任意一对键碰撞的概率为 `1/m`，键对共有 `C(n,2)` 个，所以**碰撞键对数量的期望**为：

```text
E[碰撞键对数] = C(n,2) / m
```

若 `n=100, m=10,000`：

```text
E = 100×99 / (2×10,000) = 0.495
```

这不是“发生至少一次碰撞的概率为 49.5%”。在 `n≤m` 时，至少一次碰撞的精确概率是：

```text
1 - ∏(i=0 到 n-1) (m-i)/m
```

本例约为 39.1%。一个是碰撞**对数的期望**，一个是“是否至少有一对”的事件概率，随机对象不同，不能混用。

## 11. 常见误区

- 把“有 n 种类型”直接当成每种等概率；
- 排列与组合不先判断顺序是否产生新结果；
- 并集直接相加，忘记减交集；
- 把 `P(告警|故障)` 当成 `P(故障|告警)`；
- 把互斥说成独立；
- 多次重试共享同一故障原因，却套独立乘法；
- 把期望值当作单次上限或高概率保证；
- 用期望碰撞对数冒充至少一次碰撞概率；
- 计算总方差时忽略相关性；
- 报告样本均值却不说明采样方式、窗口、样本量和异常值政策；
- 把原始样本标准差和样本均值的标准误当成同一个量；
- 把 CLT 说成“原始数据会变成正态”；
- 把 p-value 当成原假设为真的概率，或只报显著不报效果量；
- 说“随机化后最坏情况消失”。

## 做题方法

1. **定义随机对象**：一次试验是什么，X 代表成功次数、失败次数还是包含成功的总次数；
2. **写样本空间和等可能性**：不等可能时用条件概率或分组，不能只数格子；
3. **判断顺序与重复**：决定排列、组合，还是乘法原理；
4. **至少一个优先想补集**：全部不发生通常更容易相乘；
5. **条件题画频数表或概率树**：先验、检出和误报分别放在不同边；
6. **计数题使用指示变量**：先把总数写成 0/1 变量之和，再求期望；
7. **方差题检查独立或协方差**：只在有依据时删除协方差项；
8. **推断题区分三种波动**：原始样本标准差、均值标准误、置信区间宽度；写清独立性和样本量；
9. **检验题同时报效果量**：先写 H0、统计量和错误类型，再说明差异是否达到工程门槛；
10. **最后做量纲和边界验算**：概率应在 `[0,1]`，计数非负，`p=0/1`、`n=0/1` 时公式是否合理。

## 12. 计算题与完整解答

### 题 1：组合计数

8 个不同候选节点中选 3 个组成无角色副本组，共有多少种？若选出后还要指定其中一个为 leader，共有多少种？

**解答过程：**副本组不关心三者内部顺序，所以 `C(8,3)=8×7×6/(3×2×1)=56`。每个副本组又有 3 种 leader 选择，因此 `56×3=168`。也可以先选 leader 8 种，再从剩余 7 个中选 2 个 follower：`8×C(7,2)=8×21=168`，两条路径结果一致。

### 题 2：容斥

200 个失败请求中，120 个出现网络告警，80 个出现存储告警，50 个两者都有。至少出现一种告警的请求占比是多少？两种都没有的占比是多少？

**解答过程：**并集数量为 `120+80-50=150`，至少一种占比 `150/200=75%`。两种都没有是并集补集，数量 `200-150=50`，占比 `25%`。验算：四个互斥区域为仅网络 70、仅存储 30、两者 50、都无 50，总和 200。

### 题 3：Bayes 与基础率

真实故障率 2%，检测器对故障检出率 95%，对正常请求误报率 4%。看到告警后真实故障概率是多少？

**解答过程：**用 10,000 个请求便于核算。故障 200 个，其中告警 `200×0.95=190`；正常 9,800 个，其中误报 `9800×0.04=392`。总告警 `190+392=582`，所以 `P(故障|告警)=190/582≈32.65%`。验算：结果高于先验 2%，但低于检出率 95%；大量正常请求的误报解释了差距。

### 题 4：独立还是互斥

一次公平骰子中，A 表示点数为偶数，B 表示点数大于 3。它们互斥吗？独立吗？

**解答过程：**`A={2,4,6}`，`B={4,5,6}`，交集 `{4,6}` 非空，所以不互斥。`P(A)=3/6=1/2`，`P(B)=3/6=1/2`，`P(A∩B)=2/6=1/3`；若独立应有 `1/2×1/2=1/4`，但 `1/3≠1/4`，所以也不独立。

### 题 5：二项分布

每个请求独立失败且失败概率为 0.1。10 个请求中恰好 2 个失败的概率是多少？

**解答过程：**先选哪 2 个失败，有 `C(10,2)=45` 种；指定一种位置模式的概率为 `0.1²×0.9⁸`。因此：

```text
P(X=2) = 45 × 0.1² × 0.9⁸
       ≈ 0.1937
       = 19.37%
```

验算：这里 X 服从 `Binomial(10,0.1)`，期望失败数为 1；恰好 2 个不是极端结果，约 19% 的数量级合理。

### 题 6：第一次成功

每次独立尝试成功率为 0.2。第一次成功所需尝试次数 X 的期望是多少？前三次内至少成功一次的概率是多少？

**解答过程：**按“包含成功那次的次数”定义，X 是参数 `p=0.2` 的 geometric 随机变量，`E[X]=1/p=5` 次。前三次内至少一次成功用补集：`1-(1-0.2)³=1-0.512=0.488`，即 48.8%。期望为 5 不表示第五次必然成功。

### 题 7：指示变量与期望

500 个任务各自有 3% 的概率需要人工复核。无论这些事件是否独立，人工复核任务数的期望是多少？

**解答过程：**令 `I_i` 表示第 i 个任务是否复核，`E[I_i]=0.03`。总数 `R=ΣI_i`，所以 `E[R]=ΣE[I_i]=500×0.03=15`。期望线性性不要求独立；但若要计算“超过 30 个的概率”，必须知道相关结构或增加模型假设。

### 题 8：方差与相关性

两个独立处理阶段标准差分别为 6 ms 和 8 ms。总时长标准差是多少？如果二者不独立，还缺什么信息？

**解答过程：**独立时方差相加：`Var=6²+8²=100 ms²`，所以标准差 `sqrt(100)=10 ms`。不能把标准差直接相加为 14 ms。若不独立，还需要协方差：`Var(X+Y)=36+64+2Cov(X,Y)`；共享负载常让协方差为正并增大总波动。

### 题 9：哈希碰撞

50 个不同 ID 独立均匀映射到 1,000 个哈希值。碰撞键对数量的期望是多少？这能否直接当成“至少一次碰撞”的概率？

**解答过程：**键对有 `C(50,2)=1225` 个，每对碰撞概率 `1/1000`，所以期望碰撞对数为 `1225/1000=1.225`。不能把 1.225 当概率，它甚至大于 1；至少一次碰撞的概率要计算 `1-∏_{i=0}^{49}(1000-i)/1000`，约为 71.2%。多个碰撞对还可能来自同一个桶，计数对象不同。

### 题 10：区分复杂度口径

随机 pivot 快速排序可以回答“期望 `O(n log n)`，最坏 `O(n²)`”。为什么这两句不矛盾？

**解答过程：**期望对算法随机选择形成的所有执行路径按概率加权；大多数 pivot 序列能形成相对平衡的递归树。最坏界关注任何可能执行，包括每次都选到极端元素的低概率路径，该路径工作量为 `n+(n-1)+...+1=Θ(n²)`。随机化降低持续坏分割的概率，不删除这条路径。

### 题 11：Poisson 计数

某类独立事件在 10 分钟内平均出现 2 次。采用 `Poisson(λ=2)` 教学模型，10 分钟内至少出现一次的概率是多少？

**解答过程：**“至少一次”用补集。`P(X=0)=e^-2×2^0/0!=e^-2≈0.1353`，所以 `P(X≥1)=1-0.1353=0.8647`，约 86.47%。这个答案依赖固定速率和近似独立等假设；事件成批时不能照搬。

### 题 12：正态标准化

设 `X~N(100,15²)`，`X` 位于 85 到 115 之间的概率约是多少？

**解答过程：**标准化下界 `(85-100)/15=-1`，上界 `(115-100)/15=1`，所以问题变成 `P(-1≤Z≤1)`。查标准正态表约为 0.6827，即 68.27%。85 和 115 分别离均值一个标准差；若题目没有声明正态，不能只凭均值和标准差得到这个概率。

### 题 13：均值置信区间

100 次独立测量的样本均值为 50 ms、样本标准差为 10 ms。使用大样本正态近似，均值的 95% 置信区间是多少？样本量变为 400、其余近似不变时区间半宽怎样变化？

**解答过程：**`SE=10/√100=1 ms`，半宽 `1.96×1=1.96 ms`，区间 `[48.04,51.96] ms`。样本量变为 400 时 `SE=10/20=0.5 ms`，半宽约 `0.98 ms`，减半。因为标准误按 `1/√n` 缩小，样本量要增加 4 倍才能把半宽减半。

### 题 14：解释 p-value

一次 A/B 实验得到 `p=0.03`，显著性水平预先设为 0.05。可以说“新方案有 97% 概率更好”吗？

**解答过程：**不能。`p=0.03` 表示在原假设和所用模型成立时，观察到当前或更极端统计结果的概率为 3%。在预设规则下可以拒绝 H0，但它不直接给 `P(H0|data)`，也不说明效果大小或业务价值。还应报告差值、置信区间、样本设计、主要指标、第一/第二类错误，并检查是否反复试了很多指标后只挑显著结果。

## 13. 面试复述

> 概率题先定义试验、样本空间和随机变量，再判断结果是否等可能。组合题先问顺序是否重要；并集用容斥，至少一次常用补集；条件题用频数表保留基础率。期望可以用指示变量和线性性，且不要求独立；方差相加则必须处理协方差。随机算法要分别说明期望与最坏复杂度，不能把期望值当单次保证。
