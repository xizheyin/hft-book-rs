# 覆盖矩阵：知道自己究竟会了哪些模式

“我刷了 200 道题”无法说明哪些能力稳定、哪些只是刚看过答案。本章把专题拆成可验收的模式，并为每个模式设置 A/B/C/D 四级证据。你可以复制表格，每次训练只更新有证据的格子。

> A：能手算；B：能写伪代码、不变量和复杂度；C：能从空白写 C++ 并测试；D：能处理陌生变体和追问。详细定义见[训练计划](study_plan.md)。

## 1. 核心覆盖矩阵

`P0` 是本书面向基础设施、低延迟和量化开发岗位的共同地基，`P1` 是常见拓展，`P2` 按岗位选学。它们不是对所有公司的题型预测。一次打勾不算永久掌握；第 2、7、21 天仍能完成才算稳定。

| 优先级 | 模式 | A：手算任务 | B：纸上任务 | C：空白 C++ 任务 | D：迁移任务 | 入口 |
|---|---|---|---|---|---|---|
| P0 | 题意与复杂度 | 为 `n=5` 数操作次数 | 写约束、基线和 Big-O | 为优化版写边界测试 | 构造旧解失败的最小反例 | [解题流程](problem_solving.md) |
| P0 | C++ 输入输出 | 手推一组输入 | 写读取与输出格式 | 完成多组/EOF 模式程序 | 处理空行、非法范围和 C++17 平台 | [在线笔试 I/O](online_judge_io.md) |
| P0 | 线性扫描 | 逐项更新状态 | 写循环不变量 | 最大/最小/计数类函数 | 改成无限数据流 | [数组与字符串](arrays_strings.md) |
| P0 | 双指针 | 手推左右指针 | 说明排除哪段答案 | 有序 Two Sum 或原地去重 | 处理重复、返回全部答案 | [数组与字符串](arrays_strings.md) |
| P0 | 滑动窗口 | 画窗口扩缩 | 写“窗口始终合法” | 固定和、最长合法窗口 | 改成按时间窗口和乱序输入 | [数组](arrays_strings.md)、[流式](streaming_systems.md) |
| P0 | 前缀和/差分 | 手算前缀表 | 推导 `[l,r)` 公式 | 区间和与批量区间更新 | 加入历史修改或二维查询 | [数组与字符串](arrays_strings.md) |
| P0 | 哈希 | 手推 seen/counts | 写键和值的准确含义 | Two Sum、频次或去重 | 加 TTL（过期时间）、内存上限、稳定顺序 | [哈希与二分](hashing_binary_search.md) |
| P0 | 排序使用与比较器 | 手推排序后的顺序 | 说明稳定性和并列规则 | 用 `sort`/`stable_sort` 完成一道场景题 | 处理严格弱序、重复与不可修改输入 | [排序与选择](sorting_selection.md) |
| P0 | 区间/扫描线 | 画半开区间 | 写排序后的不变量 | 合并区间或最大并发数 | 加权区间、空区间和 tie-break | [哈希与二分](hashing_binary_search.md) |
| P0 | 二分 | 手推每轮区间 | 写 `first true` 不变量 | lower bound、答案二分 | 改闭区间写法并证明无死循环 | [哈希与二分](hashing_binary_search.md) |
| P0 | 栈 | 画入栈出栈 | 说明栈顶含义 | 括号或迭代遍历 | 加入错误输入与容量边界 | [栈、队列与堆](stack_queue_heap.md) |
| P0 | 队列/双端队列 | 手推 BFS/事件队列 | 写队首含义 | BFS 或先进先出事件处理 | 加容量、空队列和背压政策 | [栈、队列与堆](stack_queue_heap.md) |
| P0 | 堆/Top-K/多路合并 | 画堆中候选 | 写“答案一定在候选中” | Top-K 或 K 路合并 | 加并列顺序、持续输入和删除 | [栈、队列与堆](stack_queue_heap.md) |
| P1 | 单调栈/队列 | 画候选淘汰过程 | 说明元素为何可永久弹出 | next greater 或滑动最大值 | 循环数组、相等值与按时间过期 | [栈、队列与堆](stack_queue_heap.md) |
| P0 | 链表 | 画三根指针 | 写已反转/未处理不变量 | 反转、合并或判环 | 解释所有权模型和空指针边界 | [链表与树](linked_list_tree.md) |
| P0 | 树遍历 | 手推 DFS/BFS 顺序 | 写递归返回值或显式栈含义 | 完成一种 DFS 和层序遍历 | 改迭代版、处理深树 | [链表与树](linked_list_tree.md) |
| P1 | BST | 手推有序约束 | 写祖先上下界含义 | 验证 BST | 处理重复键、极值与深树 | [链表与树](linked_list_tree.md) |
| P2 | LCA 与树专项 | 手推祖先路径 | 写子树返回值含义 | 求最近公共祖先 | 处理节点不存在与多次查询 | [链表与树](linked_list_tree.md) |
| P0 | 图 DFS/BFS | 画 visited 变化 | 说明何时标记访问 | 连通分量、无权最短路 | 路径恢复、多源或网格建图 | [图与搜索](graph_search.md) |
| P0 | 拓扑排序 | 手推入度 | 写 ready 集合不变量 | 返回顺序并检测环 | 返回具体环、处理重复边 | [图与搜索](graph_search.md) |
| P1 | 并查集 | 手推 parent | 解释路径压缩 | 冗余连接/连通查询 | 动态加入、按大小合并 | [图与搜索](graph_search.md) |
| P1 | 非负权最短路 | 手推松弛 | 证明弹出距离已确定 | Dijkstra + 不可达 | 大权重、路径恢复、负边识别 | [图与搜索](graph_search.md) |
| P1 | 回溯 | 画选择树 | 写选择/撤销不变量 | 子集或组合 | 去重、剪枝、返回首解 | [图与搜索](graph_search.md) |
| P1 | 贪心 | 手推选择 | 写交换论证或反例 | 区间调度 | 加权后识别为何转 DP | [贪心与 DP](greedy_dp.md) |
| P1 | 基础 DP | 填一张小表 | 写状态、转移、初始化 | 一维 DP 或网格 DP | 恢复方案或压缩空间 | [贪心与 DP](greedy_dp.md)、[DP 模式](dp_patterns.md) |
| P1 | 位掩码与整数边界 | 手推二进制位 | 写 unsigned 与移位边界 | flags、异或或 `popcount` | 处理位宽、溢出和输入契约 | [位运算与数值](bit_math.md) |
| P0 | 字符串扫描与解析 | 手推字节下标 | 定义 ASCII/UTF-8 与 token 语义 | 频次、扫描或字段解析 | 处理空字段、非法数字和生命周期 | [字符串算法](string_algorithms.md) |
| P0 | 流式窗口与序号 | 手推事件序列 | 写状态、过期和缺口政策 | 滚动统计或序号检测 | 加内存上限、乱序和恢复 | [流式与工程算法](streaming_systems.md) |
| P1 | 在线统计与事件时间 | 手推增量状态 | 解释样本、watermark 与迟到政策 | 在线均值/方差或简化事件时间题 | 讨论精度、检查点和分区 | [流式与工程算法](streaming_systems.md) |
| P2 | 手写排序与选择 | 手推 merge/partition | 写分区不变量 | 归并、三路快排或 Quickselect | 处理退化、重复与随机化 | [排序与选择](sorting_selection.md) |
| P2 | 专项字符串/数值/DP | 手推前缀表或 DP 表 | 写适用前提 | KMP、Trie、快速幂、LIS 或区间 DP 中按需选择 | 流式匹配、内存上限或答案恢复 | [字符串](string_algorithms.md)、[DP](dp_patterns.md)、[数值](bit_math.md) |
| P2 | 进阶结构与图 | 手推树状数组/边选择 | 写结构不变量 | Fenwick、segment tree 或 MST | 坐标压缩、SCC、负边选择 | [进阶选学](advanced_structures.md) |

## 3. 每次冷启动记录什么

```text
日期 / 模式 / 题目：
限制时间：
第一次通过样例：__ 分钟
第一次通过全部自测：__ 分钟
是否先写暴力：是 / 否
是否说出不变量：是 / 否
是否独立写出 C++：是 / 否
错误：约束 / 不变量 / 复杂度 / C++ / 边界 / 表达
最小反例：
下一次复测：第 2 / 7 / 21 天
```

看答案后写对不计“首次通过”。超时后应继续完成并复盘，但在矩阵中记录超时，避免用最终结果抹掉过程问题。

## 4. 模拟失败怎样回跳

| 模拟失分 | 回跳 |
|---|---|
| 输入读错、输出格式错 | [在线笔试 I/O](online_judge_io.md) |
| 能写暴力但超时 | 对应模式章的关键观察和复杂度 |
| 会说思路但代码错 | [C++ 工具箱](cpp_toolbox.md)与该题 C 级重写 |
| 只过样例 | [正确性与测试](complexity_correctness.md)，补最小反例与对拍 |
| 遇到换皮认不出 | 做该模式 D 级迁移，不增加同题答案阅读 |
| 现场讲不清 | 录制 30 秒题意、2 分钟算法、5 分钟追问三版 |

修复后必须做一题**没看过的新变体**。重跑原样例只能证明你记住了修补位置。

## 5. 阶段门槛

- **可以参加基础笔试模拟**：全部 P0 达到 B，至少 12 个 P0 达到 C。
- **算法轮较充分**：全部 P0 达到 C，至少 6 个 P0 模式达到 D；一套基础卷和一套陌生混合卷限时 75 分以上。
- **冲击高性能/量化实现扩展**：只把岗位说明或模拟确实暴露的 P1 练到 C；P2 没有统一数量门槛，同时把更多时间留给系统、C++ 高阶和业务准备。

矩阵衡量的是可控训练项，不是录用概率。简历匹配、系统设计、数学/ML、项目深挖、沟通和当天题目仍会影响结果。
