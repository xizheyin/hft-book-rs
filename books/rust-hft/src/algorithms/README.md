# 数据结构、算法与 C++20 实现

数据结构规定数据之间怎样关联、怎样存储以及允许哪些操作；算法规定怎样利用这些结构得到结果。学习算法不能只记函数模板：先明确输入、输出和约束，再选择结构、写出不变量，最后才把思路翻译成 C++20，并用边界测试验证。

```mermaid
flowchart LR
    A["题意、输入与约束"] --> B["逻辑结构与操作"]
    B --> C["算法与不变量"]
    C --> D["复杂度和正确性"]
    D --> E["C++20 实现"]
    E --> F["边界与差分测试"]
```
