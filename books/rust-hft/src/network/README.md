# 网络与高性能 I/O (Network & I/O)

本部分讨论数据如何进入系统，以及 I/O 栈如何影响延迟分布、吞吐量上限与资源占用。对高性能应用而言，网络并不是一个抽象的“传输层”，而是一条由网卡、中断、驱动、内核协议栈、系统调用和用户态缓冲区共同组成的执行路径。

理解这条路径的意义在于：很多时候，程序的瓶颈并不来自业务逻辑，而来自数据在不同保护域和不同缓存层次之间的移动成本，以及这些移动成本对延迟与吞吐量的双重影响。

## 关键指标

在网络编程中，我们关注两个核心指标：

- **RTT (Round Trip Time)**: 往返时延，用于衡量端到端传输成本。
- **Jitter (抖动)**: 延迟的波动程度。对高性能系统中的时延敏感路径而言，抖动往往比平均值更值得关注。
